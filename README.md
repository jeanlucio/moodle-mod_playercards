# PlayerCards: Guardians & Lore

[English](#english) | [Português](#português)

## English

A collectible card game activity for Moodle. Course content authored by the teacher
becomes playable Info and Quiz cards, and students duel against an AI opponent to review
that content under pressure. Part of the Player ecosystem.

**Status: early development (Fase 1 of the implementation roadmap).** Not yet installable
end-to-end — no course-module UI exists yet. See `.plans/SCOPE.md` for the full design
document.

## Português

Uma atividade de jogo de cartas colecionável para o Moodle. O conteúdo cadastrado pelo
professor vira cartas Info e Quiz jogáveis, e os estudantes duelam contra uma IA para
revisar esse conteúdo sob pressão. Parte do ecossistema Player.

**Status: início de desenvolvimento (Fase 1 do roteiro de implementação).** Ainda não
instalável de ponta a ponta — não existe interface de atividade ainda. Ver
`.plans/SCOPE.md` para o documento de design completo.
